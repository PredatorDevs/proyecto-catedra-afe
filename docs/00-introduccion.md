# 00 - Introducción

Este repositorio contiene un **Project Template Empresarial** basado en AdonisJS (full-stack) con enfoque en:

- Boilerplate listo para iniciar rápido
- Layout consistente (navbar/sidebar)
- Estilos con modo claro/oscuro
- Registro / Login / Logout
- RBAC (roles y permisos)
- Bitácora parcial de acciones por usuario (audit logs)

## Objetivo del template
Servir como base reutilizable para proyectos académicos o empresariales, permitiendo iniciar con una arquitectura y estándares listos desde el día 1.

## Alcance (fase inicial)
1. Crear el proyecto AdonisJS (Web + MySQL)
2. Estandarizar repositorio y documentación
3. Integrar Tailwind + DaisyUI
4. Crear layout base + toggle de tema
5. Implementar auth (registro/login/logout)
6. Implementar RBAC
7. Implementar bitácora parcial
